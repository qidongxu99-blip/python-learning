# python-learning

我的 Python 学习代码库。

这里存的是我学 Python 过程中写的所有代码、练习和小项目，由我的 AI 助手（WorkBuddy）协助维护——每次学完新东西，助手会帮我把代码整理好放进对应文件夹，然后推送到 GitHub。

## 文件夹说明

| 文件夹 | 放什么 |
|--------|--------|
| `01_basics/` | 基础语法练习：变量、条件、循环、函数这些基本概念的小 demo |
| `02_practice/` | 刷题和小练习：课后习题、编程题 |
| `03_projects/` | 完整小项目：能跑起来的小程序，比如计算器、小爬虫 |
| `notes/` | 学习笔记：markdown 格式的知识点整理 |
| `utils/` | 常用工具函数：自己写的、能反复用的代码片段 |

## 怎么用

每次学完一个知识点，跟助手说一声，助手会：

1. 把代码写好放进对应文件夹
2. 写好注释和说明
3. 推送到 GitHub
